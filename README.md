# Hold the Hex

Local-only first pass. One hexagon hold: five walls, an opening, a small
hex base in the middle. Dots come for the base. Shapes shoot them.

```bash
npm install
npm run dev
```

Open the printed local URL (port **5176**). Not deployed.

| Shape | |
| --- | --- |
| Circle | Fast, light pulses |
| Square | Slow, heavy shot |
| Triangle | A line that pierces |

Gold from kills. The base loses energy while dots sit on it.
